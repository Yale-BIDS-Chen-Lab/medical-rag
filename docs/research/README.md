# Research

Study-specific methods, released resources, and code maps for Medical RAG research.

## Rethinking Medical RAG

**[Rethinking Retrieval-Augmented Generation for Medicine: A Large-Scale, Systematic Expert Evaluation and Practical Insights](https://arxiv.org/abs/2511.06738)**

Expert evaluation of evidence retrieval, evidence selection, and response generation. The released evaluation data covers 200 questions, 800 responses, and 3,200 retrieved passages.

[Research guide and code map](rethinking-med-rag.md) · [Dataset](https://huggingface.co/datasets/Yale-BIDS-Chen/medical-rag-expert-evaluation-200) · [Filtering model](https://huggingface.co/Yale-BIDS-Chen/Llama-3.1-8B-Evidence-Filtering)

Component usage shared across studies is documented in the [main documentation](../README.md).
